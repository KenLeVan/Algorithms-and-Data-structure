# Algorithms and Data Structures (C++ Implementation)

Этот репозиторий содержит мою личную реализацию классических алгоритмов на языке C++. 

### Цель проекта
Переход от теоретического изучения алгоритмов (курс ВШЭ "Алгоритмы и структуры данных") к практическому программированию. Моя задача — реализовать большую часть алгоритмов с нуля, чтобы глубоко разобраться в их механиках и управлении памятью в C++.

### Что реализовано на данный момент:
* **Алгоритмы сортировки**:
    Практически все виды базовых сортировок были реализованны (Быстрая сортировка, Сортировка слиянием, Сортировка кучей)
* **Алгоритмы на графах**:
    Большинство базовых алгоритмов для поиска пути между двумя вершинами (DFS, BFS, Dijkstra, Bellman-ford)
    Работа с нахождением остовного леса и нахождение максимального паросочетания
* **Алгоритмы поиска подстроки в строке**:
    Реализация КМП и Боера-Мура

### Стек технологий
* **Язык**: C++17
* **Среда**: Разработка ведется с использованием стандартной библиотеки (STL), но логика алгоритмов реализуется вручную.

### Планы по развитию
1. Реализация базовых деревьев поиска (BST).
2. Реализация топологической сортировки.
3. Ознакомление с CMake для автоматизации сборки проекта.
